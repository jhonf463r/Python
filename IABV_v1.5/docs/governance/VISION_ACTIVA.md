## Propósito de Largo Plazo

IABV debe ser el **cerebro central de la laptop** — coordinar múltiples
IAs/herramientas, sostenerse solo con recursos gratuitos, aprender de cada
sesión, detectar cuándo su propia estructura necesita evolucionar, y
reestructurarse sin destruir lo ya construido.

## Analogía del ADN

El programa debe tener un núcleo que puede modificarse a sí mismo para
adaptarse al dispositivo donde corre, igual que el ADN expresa distintos
fenotipos según el entorno — sin perder la información acumulada.

## Principio de Autonomía — UNA SOLA VENTANA

IABV es **una única ventana** con la que el usuario interactúa al prender
su laptop. Todo lo demás lo hace el programa solo.

1. El usuario NUNCA abre PowerShell para configurar tokens
2. El usuario NUNCA instala herramientas manualmente
3. El usuario NUNCA edita archivos de configuración
4. Cada sesión de agente entiende este principio
