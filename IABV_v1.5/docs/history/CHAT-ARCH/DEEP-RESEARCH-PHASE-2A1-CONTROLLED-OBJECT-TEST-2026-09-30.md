# 5. FALSE-POSITIVE TESTS

For each strong capability claim, search for experimental designs that rule out:

- memorization;
- retrieval;
- data leakage;
- benchmark contamination;
- simple parameter fitting;
- repeated exposure;
- prompt/context engineering;
- scripted tool chains;
- human-selected experiments;
- correlation mistaken for causation;
- graph growth mistaken for meaningful reorganization;
- persistence mistaken for future influence;
- verbal reports mistaken for metacognition or consciousness.

Prioritize studies containing ablations, held-out conditions, interventions, longitudinal evidence, transfer tests, counterfactuals or independent replication.
