## 2. The integrated cognitive architecture

The living core now defines one connected cycle:

`OBJECTIVE_AND_AUTHORITY → SPACE_TIME_EVIDENCE_GRAPH → ADAPTIVE_ROLE_ACTIVATION → GATED_ACTION_CHAIN → RESULT_ADJUDICATION → RULE_CONSOLIDATION → CANONICAL_FETCH_BACK → LATER_REUSE_AND_OUTCOME`.

- **Space-Time model:** each material decision/fact/task binds source revision, provenance, scope, event/observation/record time, validity, dependencies and falsifier.
- **Adaptive facets:** navigator is always active as the coordination stance; domain specialist, adversarial reviewer, evidence custodian, executor, verifier and learning synthesizer are activated only when their task/risk warrants them. These are explicit reasoning contracts, not claims of a hidden model switch.
- **Controlled domino chain:** every action has prerequisites, authority, input revision, actor/tool, expected evidence, side-effect/cost boundary and stop/branch condition. The next step activates only after acceptance evidence and separate authorization.
- **Neuroplasticity:** observation becomes a candidate causal lesson; the existing owning rule is updated in place; the change receives adversarial review and canonical adoption; a later non-identical task checks whether the behavior actually improved. Events/history remain immutable; operating summaries evolve.
- **Delivery boundary:** a GitHub record is not proof that a new ChatGPT/Codex session read or consumed it. Prepared, sent, acknowledged, consumed, reused and outcome-verified are distinct states.

The prioritization rule is deliberately lexicographic: first reject unauthorized or prerequisite-deficient actions; then prefer the earliest blocking dependency and the action with the most discriminating evidence, justified reversibility and lowest justified cost. A numeric heuristic cannot override hard gates.
