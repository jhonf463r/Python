The strongest reusable methodological lesson is that cross-AI orchestration must never be a fixed historical pipeline.

Use:

```

```

A previous agent's `NEXT ACTOR` or `NEXT EDGE` is evidence about the prior state, not authority over the current routing decision.

Therefore every new prompt must recompute:
- what is true now;
- which edges are already closed;
- what is the first unresolved edge;
- what capability is missing to discriminate it;
- which available actor has the strongest demonstrated fit at the current frontier;
- whether the actor has the artifact/runtime access required;
- whether the intervention cost is justified.

### Semantic-next-edge vs actionable-next-edge

A prior report may identify a meaningful future semantic edge while the immediate actionable edge is still provenance, runtime, publication, verification, isolation, or another prerequisite.

Do not jump from a semantic next edge to implementation/research while a stronger upstream evidential gate remains open.

### Do not repeat closed work

Once an edge is closed with sufficiently strong evidence, do not spend another actor merely to repeat it unless:
- new contradictory evidence appears;
- the previous evidence class is materially weaker than the present claim;
- or the objective has changed.

## 6. BIO-04 — KNOWLEDGE PLASTICITY IS DEEPER THAN MEMORY ACCUMULATION

The central conceptual breakthrough is:

```
memory accumulation
≠
knowledge plasticity
```

And:

```
score change
≠
knowledge revision
```

Three levels must remain distinct:

1. **Memory update** — save a new observation.
2. **Belief/knowledge revision** — change the interpretation of something already believed.
3. **Topology reorganization** — change relationships between concepts, actors, tools, capabilities, contexts or resources.

The desired developmental loop is:

```
new experience
→ comparison against existing knowledge
→ confirmation / contradiction / specialization / generalization / duplication
→ epistemic update
→ relationship reorganization
→ future reuse
```

## 11. ACCUMULATION vs ADAPTATION vs REVISION vs REORGANIZATION

Future experiments should measure these as separate phenomena:

```
ACCUMULATION
→ new information coexists with prior information

ADAPTATION
→ scores/preferences change

REVISION
→ prior knowledge is modified or reclassified

REORGANIZATION
→ the relation/topology of knowledge changes

CAUSAL LEARNING
→ verified experience changes a later decision/action

IMPROVEMENT
→ that change improves a measured outcome
```

A system can improve a routing score without revising a conceptual belief.
A system can revise knowledge without improving the next outcome.
A system can accumulate enormous memory while suffering from stale or contradictory knowledge.

Therefore future claims must identify the exact layer demonstrated.
