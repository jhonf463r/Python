## 4. INITIAL MODEL / FINAL MODEL

INITIAL_MODEL=
A sufficient path might be: canonical context exists → ToolTeachService builds task → adapter sends task → agent receives it → cognitive loop exists.

FINAL_MODEL=
A chain is only closed at the highest claim level when every causal boundary is separately evidenced:
`canonical IABV state → cognitive bootstrap → real agent receipt → agent consumes context → decision → action → observation → verification → persisted STATE_B → independent second bootstrap → second agent continuation → learning → future decision change`.

MODEL_DELTA=The proof target shifted from component presence and transport integrity to causal continuity and verified learning.

WHAT_CHANGED=The meaning of “loop closed” became stricter.
WHY=Repeated false-positive patterns showed that static wiring, passing tests, and successful transport do not establish causal agent use or learning.
EVIDENCE=R5 loopback and exact STATE_A runtime were useful because they demonstrated lower-level boundaries while explicitly failing to prove higher-level boundaries.
WHO_CHANGED_IT=The change emerged through interaction among ChatGPT synthesis, Devin live observation, Claude adversarial review, and Codex implementation.
CONSEQUENCE=Future work should spend effort on discriminating causal experiments rather than adding undifferentiated architecture.
