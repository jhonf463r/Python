Materialize the project's accumulated vision of IABV as a progressively more capable developmental system by making existing inspection, audit, cross-validation, routing and persistence mechanisms operate together as a cumulative methodological substrate.

This is a protocol/method amendment, not a claim that the current runtime is already autonomous or conscious.

```

```

The developmental target is not merely more stored data. It is verified experience becoming reusable knowledge/method/routing that changes later decisions.

## 3. Symbiosis is an epistemic control loop, not an organ

Do not create a new "brain", coordinator, memory or universal registry merely to represent this method.

Use the existing organs and actors according to capability and independence:

- source/code inspection;
- repository provenance and exact-state verification;
- static architectural tracing;
- runtime observation when the edge requires it;
- adversarial semantic challenge;
- external scientific/source research when the question is external to the repository;
- synthesis and canonical writeback.

Different AIs are epistemic instruments with different observation capabilities. Agreement is not proof. A self-analysis produced by IABV remains a hypothesis until independently verified when the claim is material.

Required pattern:

```
perspective A
→ perspective B / independent challenge
→ contradiction/support classification
→ minimum discriminating observation
→ evidence
→ reconciliation
→ durable delta
```

Actor selection is capability-fit + independence + execution/evidence readiness, never message-count or historical role inheritance.

## 4. Cumulative developmental object

For every material episode, preserve a compact longitudinal object:


The project should accumulate deltas, not merely transcripts.

Formal bookkeeping model:

```
K_(t+1) = K_t ∪ verified(ΔK_t)
M_(t+1) = promote(M_t, verified(ΔM_t))
R_(t+1) = revise(R_t, verified(ΔR_t))
```

These are operational bookkeeping equations, not scientific laws.

A delta cannot enter the durable knowledge/method/routing state solely because an AI asserted it.

## 5. Evidence triangulation

For material claims, seek evidence along distinct dimensions where the edge requires it:

1. source semantics;
2. causal call-chain position;
3. exact artifact/provenance;
4. runtime observation;
5. independent interpretation/challenge;
6. later reuse or regression outcome.

Do not count correlated repetitions as independent evidence.

The minimum triangulation question is:

```
"What independent observation could distinguish the leading interpretation
from its strongest competing interpretation?"
```

This becomes the default question for the symbiosis.

## 6. World/project model accumulation

More data does not automatically mean more knowledge or certainty.

The cumulative state should distinguish:

```
observation count
≠ information gain
≠ independent evidence
≠ verified knowledge
≠ causal explanation
≠ reusable method
```

Where a probabilistic model is justified, information gain may be reasoned about as:

```
IG = H(prior) - H(posterior)
```

or, for actor/action selection, by expected information gain over possible observations.

These equations are decision-theoretic scaffolds, not evidence by themselves. Do not assign false numerical precision when probabilities are not calibrated.

## 7. Progress toward learning

The following diagnostic measures are permitted only as local indicators:

```
Verification Coverage
= independently verified material claims / material claims assessed

Reuse Coverage
= later eligible decisions that use prior verified deltas / eligible later decisions

Causal Learning Evidence
= 1 only when a verified prior delta is shown to alter a later non-identical decision/action
  under a testable condition

Coordination Reduction
= baseline routine coordination work − routine coordination work after verified reuse
```

No single scalar score may certify intelligence, learning, universality or neuroplasticity.

The strongest milestone remains qualitative and causal:

```
verified experience
→ reusable change
→ later non-identical reuse
→ changed future decision
→ observable consequence
```

Until that link is observed, the state must be called **cumulative methodological memory**, not autonomous learning.

## 8. Plasticity target

The operational analogue of neuroplasticity is:

```
verified deficit/experience
→ capability hypothesis
→ existing-organ composition
→ isolated change
→ verification
→ governed promotion/rejection/rollback
→ Knowledge/Method/Routing Delta
→ contextual reuse
→ changed later decision
```

The plasticity claim is satisfied only if the later decision changes for the relevant learned reason, not merely because a file, score, timestamp or preference was persisted.

Preserve:

```
writeback ≠ learning
retrieval ≠ learning
recommendation ≠ reuse
reuse ≠ behavioral change
behavioral change ≠ causal attribution
```

## 9. Self-help threshold

The minimum meaningful "IABV helps itself" capability is a closed loop in which the system can:

1. detect a verified limitation;
2. formulate the missing capability or uncertainty;
3. identify the evidence required;
4. select a capability-fit actor/realization;
5. execute the smallest discriminating action;
6. verify the outcome independently;
7. update reusable knowledge/method/routing;
8. encounter a later non-identical case;
9. reuse the update without being manually told the answer;
10. produce an observable consequence.

This is the first practical target for the Universal Adaptive Algorithm. It does not require full autonomy or consciousness.
