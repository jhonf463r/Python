# 8. DELTA DISCRIMINATION

Use:

ΔW = parameter/weight change
ΔM = memory/storage change
ΔK = semantic knowledge/belief change
ΔR = relation/topology/organization change
ΔC = context/conditioning change
ΔD = future decision/action-selection change
ΔB = behavior change
ΔO = downstream outcome change

Explicitly distinguish:

ΔM ≠ learning by itself
ΔW ≠ semantic knowledge revision
ΔK ≠ relation reorganization
ΔR ≠ future decision influence
ΔD ≠ causal improvement
ΔB ≠ understanding
verbal self-report ≠ metacognition
automated experimentation ≠ self-directed experimentation.

For each domain identify which deltas are actually measured in strong studies.

- memorization;
- retrieval;
- training/evaluation leakage;
- benchmark contamination;
- simple parameter fitting;
- repeated exposure;
- prompt/context manipulation;
- scripted tool chains;
- human-selected experiments;
- correlation mistaken for causation;
- graph expansion mistaken for meaningful relation reorganization;
- persistence mistaken for future causal influence;
- verbal confidence mistaken for metacognitive control.

Prefer ablation, held-out, intervention, longitudinal, transfer/generalization, counterfactual and replication designs where available.
