## Prioritized action map — 2026-09-21

## PURPOSE

Convert the 2026-09-20/21 chat-derived deductions into executable, persistent work items without leaving strategic ideas only in conversation.

This roadmap is subordinate to current repository/runtime evidence and to the canonical operational-memory protocol.

## STRATEGIC PRINCIPLE

The fastest development path is not to add architecture indiscriminately.

It is to make existing IABV organs work as a measurable causal circuit:

`objective → self-observation → uncertainty → change-surface analysis → hypothesis → smallest discriminating experiment → verification → Knowledge Delta → future decision`.

The target is IABV using its own symbiosis while retaining external independent verification.

## ROUTING RULE

For each task:
- IABV/native organs first for self-assessment;
- Sonnet for independent audit;
- Devin for bounded implementation/Windows runtime;
- Codex for difficult technical seam;
- Opus 5 only for genuine architecture/ownership contradiction;
- ChatGPT for reconciliation/writeback.

This is capability-driven, not a fixed sequence.

## STOP CONDITIONS

Stop implementation and reconcile when:
- two organs appear to own the same semantic responsibility;
- self-analysis changes the state it is observing;
- a claim has no exact provenance;
- a test bypasses the real branch;
- persistence is being mistaken for learning;
- a new service is proposed only because existing organs are difficult to compose.

## SUCCESS GATE

This roadmap is materially advancing only when an IABV-native self-assessment can produce a useful, evidence-qualified next experiment and that result can be independently verified and fed into the next decision.
