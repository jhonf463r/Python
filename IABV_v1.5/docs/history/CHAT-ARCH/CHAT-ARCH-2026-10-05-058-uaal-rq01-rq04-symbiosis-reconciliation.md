## WHAT HAS BEEN LEARNED ABOUT THE UNIVERSAL-PROGRAM OBJECTIVE

The project should not test “does IABV understand Paint?” as a binary one-off.

The reusable scientific/engineering question is:

`Can IABV construct a transferable representation of an unfamiliar environment from heterogeneous observations and use verified affordance/causal knowledge to act better on that or another realization later?`

For an unfamiliar program:

`raw observation → normalized entities/relations/state → semantic role hypotheses → affordances → uncertainty → exploratory action → observed transition → verification → instance memory → pattern abstraction → future reuse`

Memory should distinguish at least:

- INSTANCE — current program/session facts;
- PATTERN — reusable structural patterns;
- CAUSAL — action→transition evidence;
- CAPABILITY — what a channel can do under constraints;
- META-KNOWLEDGE — source reliability, provenance, independence and uncertainty.

Similarity should be structural/semantic/causal/contextual, not merely name/coordinate/selector matching.

No current evidence justifies claiming this universal learning loop is implemented end-to-end.
