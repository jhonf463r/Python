RAW GIT IDENTITY
===============

Git identity is included in 01_GIT_IDENTITY_RAW.txt with:
- git show --no-patch --format=fuller
- git log --oneline -1
- git rev-parse HEAD
- git rev-parse HEAD~1
- git rev-parse HEAD^{tree}
- git branch --show-current
- git remote -v

This provides complete commit provenance for the audit.
