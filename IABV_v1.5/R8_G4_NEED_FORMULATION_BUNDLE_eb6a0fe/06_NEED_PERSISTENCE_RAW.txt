REPOSITORY METHODS:
- upsert(need): Insert or update a need
- get(need_id): Retrieve a need by ID
- list_all(): Return all needs sorted by created_at (newest first)
- list_pending(): Return only PENDING needs
- update_status(need_id, status): Update need status
- summary(): Return machine-readable summary
