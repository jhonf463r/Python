## Issue Summary
The independent audit of commit 05190c64a concluded G1_FINAL_PASS_WITH_DEBT with G1_CLOSED = NO.
The dominant debt identified was REASONING → ACTION.

Currently G1 demonstrates:
GOAL → REAL PROVIDER → PLAN → assigned_tool = write_repo_file → C2 → effect

But the human/harness still explicitly provides:
- relative_path
- content

And the planner is practically forced to choose:
- write_repo_file

Therefore, G1 still does not demonstrate that the system formulates a complete executable action.

## Root Cause Analysis
The planner contract was incomplete - it only provided assigned_tool and tool_rationale.
The G1 entry point consumed human-provided tool_parameters instead of plan-generated parameters.
There was no expected_result field in the plan for verification.

## Fixes Applied

### 1. Extended Planner Contract (src/iabv_v15/services/adaptive/cloud_reasoning_planner.py)
- Added target, parameters, expected_result, rationale fields to PlanStep
- Updated system prompt to instruct planner to generate these fields
- Updated _parse_plan to extract these fields from LLM response

### 2. Updated G1 Entry Point (src/iabv_v15/infra/mcp/server.py)
- Extract plan_target, plan_parameters, plan_expected_result, plan_rationale from plan
- Use plan_parameters instead of human-provided tool_parameters when plan is non-empty (G2 case)
- Maintain backward compatibility: use human tool_parameters when plan is empty (G1 case)
- Extract target from plan for capability acquisition
- Add expected_result vs observed_result comparison logic
- Return result_verification status (verified, verification_failed, skipped, error)

### 3. Created G2 Tests (tests/windows_e2e/test_g2_goal_to_action_plan.py)
- test_g2_goal_to_action_plan: Positive test with human providing ONLY goal
- test_g2_verification_negative: Negative test with wrong expected_result
- Both tests demonstrate real provider, real plan, real execution, real verification

### 4. Updated G1 Negative Test (tests/windows_e2e/test_g1_goal_to_protected_tool.py)
- Added target, expected_result, rationale to MockStep for G2 compatibility
- Maintains real rejection of unsupported tools
