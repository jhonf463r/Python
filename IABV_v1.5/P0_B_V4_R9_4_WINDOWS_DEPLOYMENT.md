## PHASE 6: PROVISION AUTHORITY KEY

### Step 6.1: Authority Key Provisioning (Service Context)

F14 V4-r9.4 FIX: Authority key must be generated by the service process itself
running under LocalService, NOT from Administrator PowerShell.

**CRITICAL SECURITY NOTE:**
DPAPI encryption is tied to the identity of the calling process. If you call
generate_and_store_key() from Administrator PowerShell, the key will be
protected under Administrator identity and the service (LocalService) will
NOT be able to decrypt it.

The correct procedure is:
1. Install and configure the service to run as LocalService
2. Start the service in provisioning mode
3. The service generates the key under its own identity
4. Stop the service
5. Restart in normal mode

### Step 6.2: Start Service in Provisioning Mode

```powershell
# Run as Administrator
$env:IABV_AUTHORITY_PROVISIONING="1"
python -m iabv_v15.services.development.authority_windows_service start
```

**Expected Output:**
```
Service started: IABVAuditAuthority
```

The service will:
- Start in provisioning mode (allow_provisioning=True)
- Detect missing authority key
- Generate key under LocalService identity
- Store key with DPAPI protection for LocalService
- Enter READY state

### Step 6.3: Verify Key Generation

```powershell
# Run as Administrator
Get-Content "C:\ProgramData\IABV\authority_keys\authority_private_key.json"
```

**Expected Output:**
```json
{
  "key_id": "<16-char hex>",
  "public_key_hex": "<64-char hex>",
  "private_key_protected": "<DPAPI-encrypted hex>",
  "protection": "DPAPI",
  "service_identity": "LocalService",
  "created_at_utc": "<ISO timestamp>",
  "dpapi_identity_warning": "This key is protected under the identity of the process that called generate_and_store_key(). If called from Administrator, LocalService cannot decrypt it."
}
```

### Step 6.4: Stop Service After Provisioning

```powershell
# Run as Administrator
python -m iabv_v15.services.development.authority_windows_service stop
```

### Step 6.5: Restart Service in Normal Mode

```powershell
# Run as Administrator (no provisioning flag)
python -m iabv_v15.services.development.authority_windows_service start
```

The service will now:
- Start in normal mode (allow_provisioning=False)
- Load the existing key (fail-closed if missing)
- Verify DPAPI decryption works under LocalService
- Enter READY state

**Status:**
- ✅ IMPLEMENTED in V4-r9.4
- AuthorityKeyManager.generate_and_store_key() creates key with DPAPI under current process identity
- AuthorityKeyManager.load_key() loads and decrypts key with identity verification
- Service supports provisioning mode via IABV_AUTHORITY_PROVISIONING=1
- Normal runtime fails closed if key is missing

## TROUBLESHOOTING

### Service Installation Fails

**Error:** Access denied
**Solution:** Run PowerShell as Administrator

**Error:** pywin32 not found
**Solution:** Install pywin32: `pip install pywin32`

### Service Won't Start

**Error:** Service start failed
**Solution:** Check Windows Event Viewer for service logs

**Error:** Key storage directory not found
**Solution:** Create directory and configure ACL

### ACL Configuration Fails

**Error:** Access denied
**Solution:** Run PowerShell as Administrator

**Error:** Invalid parameter
**Solution:** Verify path format (use forward slashes or escape backslashes)

### IPC Connection Fails

**Error:** Pipe not found
**Solution:** Verify service is running

**Error:** Access denied
**Solution:** Verify caller is authorized

## SECURITY NOTES

### Critical Security Boundaries

1. **Service Identity:**
   - Must be LocalService (NOT LocalSystem)
   - Normal user cannot access service resources

2. **ACL Enforcement:**
   - Users group must have Read only (no Write/Delete)
   - Administrators must have Full Control
   - Service identity must have Full Control for key storage

3. **IPC Authorization:**
   - Named Pipe must restrict to authorized callers
   - Caller SID must be validated
   - CERTIFY must not expose private key

### Fail-Closed Behavior

- Service must fail if key missing
- Service must fail if key corrupted
- Service must fail if ACL incorrect
- Runtime must fail if trust anchor missing
- Runtime must fail if trust anchor corrupted
