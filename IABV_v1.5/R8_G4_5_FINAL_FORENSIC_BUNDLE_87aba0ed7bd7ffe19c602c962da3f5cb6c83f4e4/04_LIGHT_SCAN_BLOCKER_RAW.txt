ROOT CAUSE:
===========

The EnvironmentSelfAwarenessService.__init__ method was blocking during LIGHT_SCAN because:

1. The test did not set PYTEST_CURRENT_TEST environment variable
2. _cpu_snapshot() at line 967-988 checks self._in_test_mode() which returns False without PYTEST_CURRENT_TEST
3. Even with full=False, _cpu_snapshot() still executes PowerShell command via _powershell_json()
4. The subprocess call with 1.0 second timeout was hanging on this Windows system
