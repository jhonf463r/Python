WHO GENERATES REQUESTS:
-----------------------
Based on code analysis:

1. ToolTeachService
   - Selects prompt_template_id based on tool_id
   - Generates consultation request with goal, context, parameters
   - Called by: ControlCenterViewModel._run_external_consultation()

2. CloudReasoningPlannerService
   - Generates API requests to cloud providers
   - Formats messages for OpenAI/Groq/Gemini/Ollama APIs
   - Called by: AdaptiveTaskOrchestrator

3. Devin repair
   - Generates prompt for Devin API
   - Called by: ControlCenterViewModel._try_devin_repair()

INPUT:
------
Based on code analysis:
- ToolTeachService: goal, goal_parameters, context (world model, episodes)
- CloudReasoningPlannerService: messages (list of chat messages), model name
- Devin repair: prompt (error description, context)

OUTPUT:
------
Based on code analysis:
- ToolTeachService: consultation request (with prompt_template_id, goal, context)
- CloudReasoningPlannerService: HTTP request to provider API
- Devin repair: HTTP request to Devin API
