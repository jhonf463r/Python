WHO TRIGGERS CONSULTATION:
--------------------------
Based on code analysis:

1. CloudReasoningPlannerService
   - Calls provider APIs (openai, groq, gemini, ollama)
   - Triggered by: AdaptiveTaskOrchestrator, UI requests
   - Purpose: Cloud reasoning for tasks

2. ToolTeachService
   - Runs external consultation via tools
   - Triggered by: UI (ControlCenterViewModel._run_external_consultation)
   - Purpose: Consult external assistants for help

3. ControlCenterViewModel
   - Has _run_external_consultation() method
   - Triggered by: UI actions (user commands like "consultar claude")
   - Purpose: User-initiated consultation

4. Devin repair
   - Triggered by: ControlCenterViewModel._try_devin_repair()
   - Purpose: Autonomous repair via Devin API

INPUT:
------
Based on code analysis:
- CloudReasoningPlannerService: messages (list of chat messages), model name
- ToolTeachService: goal, goal_parameters, context
- Devin repair: prompt (error description, context)

OUTPUT:
------
Based on code analysis:
- CloudReasoningPlannerService: JSON response with reasoning, code suggestions
- ToolTeachService: consultation result (captured as episode)
- Devin repair: session_id, session_url, session_status

AUTOMATIC vs HUMAN-TRIGGERED:
-----------------------------
Based on code analysis:
- CloudReasoningPlannerService: AUTOMATIC (called by orchestrator)
- ToolTeachService: HUMAN-TRIGGERED (via UI commands)
- Devin repair: AUTOMATIC (triggered on certain errors)

NEED → CONSULTATION TRANSFORMATION:
----------------------------------
Based on code analysis:
- NO transformation from NEED → CONSULTATION found
- Consultation is triggered by:
  1. Task execution (CloudReasoningPlannerService)
  2. User commands (ToolTeachService)
  3. Error conditions (Devin repair)
- NO need formulation service exists (from previous audit)
- Therefore, NO need → consultation transformation exists

DOWNSTREAM EFFECT:
-----------------
Based on code analysis:
- CloudReasoningPlannerService: Provides reasoning for task execution
- ToolTeachService: Captures consultation as episode for learning
- Devin repair: Creates remote session for code repair

CONCLUSION:

EXTERNAL AI CONSULTATION EXISTS:

- External assistants (ChatGPT, Claude, Devin) for consultation
- Local LLM (Ollama) for local reasoning

However:
- NO transformation from NEED → CONSULTATION
