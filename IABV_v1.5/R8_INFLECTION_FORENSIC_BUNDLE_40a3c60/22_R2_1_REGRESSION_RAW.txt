R2.1 VULNERABILITY DESCRIPTION
-----------------------------

The VFINAL5-R2.1 vulnerability allowed bypassing security-critical path restrictions using uppercase or mixed-case paths:
- Lowercase denylist: "services/trust/", "security/", "bootstrap.py", ".git/config"
- Bypass: "SERVICES/TRUST/", "SECURITY/", "BOOTSTRAP.PY", ".GIT/CONFIG"
- Root cause: Path comparison was case-sensitive on case-insensitive filesystems (Windows)

---

FIX IMPLEMENTATION
------------------

File: src/iabv_v15/services/trust/authority_protocol.py
Function: canonicalize_target() (lines 28-106)

Key fix (line 74):
```python
# VFINAL5-R3: Platform-independent case-insensitive normalization
# Security policy must be consistent across all platforms (Windows, Linux, CI, container)
# Case-sensitive or case-insensitive filesystem semantics must be handled explicitly
# For security-sensitive path classification, we normalize to lowercase
normalized_path = normalized_path.lower()
```

The fix normalizes all paths to lowercase before policy evaluation, ensuring:
- "file:src/IABV_V15/SERVICES/TRUST/foo.py" → "file:src/iabv_v15/services/trust/foo.py"
- "file:src\\iabv_v15\\SERVICES\\TRUST/foo.py" → "file:src/iabv_v15/services/trust/foo.py"
- "file:BOOTSTRAP.PY" → "file:bootstrap.py"
- "file:.GIT/config" → "file:.git/config"
