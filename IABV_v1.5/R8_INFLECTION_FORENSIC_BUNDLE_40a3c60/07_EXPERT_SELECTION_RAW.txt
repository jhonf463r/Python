WHAT IT DOES:
-------------
Based on code analysis (lines 1-200):
- Auto-selects the best model/provider based on observed latency, error rates, task type
- Reads recent performance from DecisionAuditTrail
- Scores each available provider by: latency, success rate, quota status
- Returns the best provider for the current task type
- Detects degradation patterns (slow latency, quota exhaustion, repeated failures)

MODEL/PROVIDER SELECTION vs EXPERT SELECTION:

- This is MODEL/PROVIDER selection (OpenAI vs Groq vs Ollama)
- NOT expert selection (ChatGPT vs Claude vs Devin)
- The selector chooses between providers (e.g., 'openai', 'groq', 'ollama_local')
- It does NOT choose between AI assistants/experts

- scores: all provider scores

- quota_rotation_applied: whether quota rotation was applied

DOWNSTREAM EFFECT:

- If provider fails, fallback chain is tried
- Performance is recorded back to DecisionAuditTrail
