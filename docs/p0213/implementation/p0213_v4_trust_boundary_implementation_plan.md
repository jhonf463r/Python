## A. Root Trust Anchor

### Definition

The root trust anchor is the combination of OS-controlled runtime state that cannot be forged by caller input.

### Components

1. **Process Identity**
   - `os.getpid()` - Current process PID (OS-controlled)
   - `psutil.Process(pid).create_time()` - Process creation timestamp (OS-controlled)
   - `psutil.Process(pid).ppid()` - Parent process PID (OS-controlled)

2. **Runtime Identity**
   - Bootstrap timestamp (persisted at startup, OS-controlled)
   - Runtime generation (persisted counter, OS-controlled)
   - Secret key (persisted at first startup, OS-controlled)

3. **OS API Trust**
   - `GetNamedPipeClientProcessId()` - Authentic client PID from OS (Windows Vista+)
   - Windows Security API (SECURITY_DESCRIPTOR, DACL) - Process-specific access control

### Trust Anchor Properties

- **OS-controlled**: Cannot be forged by caller input
- **Persisted**: Survives process restart
- **Verifiable**: Can be validated against OS state
- **Immutable**: Cannot be modified after issuance

### Implementation

```python
class RootTrustAnchor:
    """Root trust anchor combining OS-controlled runtime state."""
    
    def __init__(self, storage_root: Path):
        self.storage_root = storage_root
        self._secret_key = self._load_or_generate_secret_key()
        self._generation = self._load_generation()
        self._bootstrap_timestamp = self._load_bootstrap_timestamp()
    
    def get_process_identity(self) -> ProcessIdentity:
        """Get OS-controlled process identity."""
        return ProcessIdentity(
            pid=os.getpid(),
            create_time=psutil.Process().create_time(),
            ppid=psutil.Process().ppid(),
        )
    
    def get_runtime_identity(self) -> RuntimeIdentity:
        """Get OS-controlled runtime identity."""
        return RuntimeIdentity(
            generation=self._generation,
            bootstrap_timestamp=self._bootstrap_timestamp,
        )
```

## B. Identity Issuance

### Design

Identity issuance must be the ONLY way to create valid identities. Caller-constructed identities must be rejected.

### Issuance Flow

```
RootTrustAnchor
    ↓
ProcessIdentity + RuntimeIdentity
    ↓
Cryptographic Signing (HMAC-SHA256)
    ↓
TrustedExecutionIdentity
```

### TrustedExecutionIdentity Structure

```python
@dataclass(frozen=True)
class TrustedExecutionIdentity:
    """Identity that can ONLY be issued by RuntimeIdentityAuthority."""
    
    # Issuer
    issuer_pid: int  # PID of issuing process
    issuer_generation: int  # Generation of issuing runtime
    
    # Execution
    execution_id: str  # UUID generated by authority
    run_id: str  # UUID generated by authority
    episode_id: str | None
    session_id: str | None
    invocation_id: str  # UUID generated by authority
    
    # Runtime binding
    runtime_generation: int  # From RootTrustAnchor
    bootstrap_timestamp: float  # From RootTrustAnchor
    
    # Cryptographic proof
    signature: str  # HMAC-SHA256 of all fields
    
    # Metadata
    issued_at: float  # Unix timestamp
    expires_at: float  # Unix timestamp
```

### Issuance Rules

1. **Authority-only**: Only RuntimeIdentityAuthority can issue identities
2. **Cryptographic binding**: All fields signed with secret key
3. **Runtime binding**: Includes runtime generation and bootstrap timestamp
4. **Process binding**: Includes issuer PID
5. **Expiration**: Identity expires after TTL

### Anti-Fabrication

```python
class RuntimeIdentityAuthority:
    """Authority that issues trusted identities."""
    
    def issue_identity(
        self,
        run_id: str | None = None,
        episode_id: str | None = None,
        session_id: str | None = None,
        ttl_seconds: int = 3600,
    ) -> TrustedExecutionIdentity:
        """Issue a trusted execution identity."""
        
        # Generate UUIDs (authority-controlled)
        execution_id = str(uuid4())
        invocation_id = str(uuid4())
        
        # Get runtime state (OS-controlled)
        process_identity = self._trust_anchor.get_process_identity()
        runtime_identity = self._trust_anchor.get_runtime_identity()
        
        # Create identity (unsigned)
        identity = TrustedExecutionIdentity(
            issuer_pid=process_identity.pid,
            issuer_generation=runtime_identity.generation,
            execution_id=execution_id,
            run_id=run_id or execution_id,
            episode_id=episode_id,
            session_id=session_id,
            invocation_id=invocation_id,
            runtime_generation=runtime_identity.generation,
            bootstrap_timestamp=runtime_identity.bootstrap_timestamp,
            signature="",  # Will be filled
            issued_at=time.time(),
            expires_at=time.time() + ttl_seconds,
        )
        
        # Sign identity
        signature = self._sign_identity(identity)
        identity = dataclasses.replace(identity, signature=signature)
        
        return identity
```

## C. Identity Verification

### Design

Verification must distinguish between ISSUED_BY_AUTHORITY and CONSTRUCTED_BY_CALLER.

### Verification Flow

```
TrustedExecutionIdentity
    ↓
Extract fields
    ↓
Recompute HMAC
    ↓
Compare with provided signature
    ↓
Verify runtime generation
    ↓
Verify bootstrap timestamp
    ↓
Verify issuer PID
    ↓
Verify expiration
    ↓
VALID or INVALID
```

### Verification Rules

1. **Signature verification**: HMAC must match
2. **Runtime generation**: Must match current generation
3. **Bootstrap timestamp**: Must match current bootstrap timestamp
4. **Issuer PID**: Must be from same process or authorized parent
5. **Expiration**: Must not be expired
6. **Fail-closed**: Any failure → reject

### Implementation

```python
class RuntimeIdentityAuthority:
    """Authority that verifies trusted identities."""
    
    def verify_identity(
        self,
        identity: TrustedExecutionIdentity,
    ) -> bool:
        """Verify a trusted execution identity."""
        
        # 1. Verify signature
        if not self._verify_signature(identity):
            return False
        
        # 2. Verify runtime generation
        current_generation = self._trust_anchor.get_runtime_identity().generation
        if identity.runtime_generation != current_generation:
            return False
        
        # 3. Verify bootstrap timestamp
        current_bootstrap = self._trust_anchor.get_runtime_identity().bootstrap_timestamp
        if identity.bootstrap_timestamp != current_bootstrap:
            return False
        
        # 4. Verify issuer PID (same process or authorized parent)
        current_pid = self._trust_anchor.get_process_identity().pid
        if identity.issuer_pid != current_pid:
            # TODO: Verify parent-child relationship
            return False
        
        # 5. Verify expiration
        if time.time() > identity.expires_at:
            return False
        
        return True
    
    def _verify_signature(self, identity: TrustedExecutionIdentity) -> bool:
        """Verify HMAC signature."""
        # Recompute HMAC
        expected_signature = self._compute_signature(identity)
        return identity.signature == expected_signature
```

## D. Cryptographic Enforcement

### Design

If HMAC is used, it must be signed, transported, and verified. "signature exists" is NOT evidence of security.

### Key Management

1. **Key owner**: RuntimeIdentityAuthority (singleton)
2. **Key storage**: File in `data/evolution/identity/secret.key` (OS-controlled)
3. **Key generation**: Generated at first startup, persisted
4. **Key rotation**: On generation increment (runtime restart)

### HMAC Algorithm

- **Algorithm**: HMAC-SHA256
- **Key size**: 256-bit (32 bytes)
- **Input**: All identity fields (except signature itself)
- **Output**: 64-character hex string

### Signing Process

```python
def _sign_identity(self, identity: TrustedExecutionIdentity) -> str:
    """Sign identity with HMAC-SHA256."""
    
    # Create message from all fields (except signature)
    message = self._serialize_identity(identity)
    
    # Compute HMAC
    signature = hmac.new(
        self._trust_anchor._secret_key,
        message.encode('utf-8'),
        hashlib.sha256,
    ).hexdigest()
    
    return signature
```

### Verification Process

```python
def _verify_signature(self, identity: TrustedExecutionIdentity) -> bool:
    """Verify HMAC signature."""
    
    # Create message from all fields (except signature)
    message = self._serialize_identity(identity)
    
    # Compute expected HMAC
    expected = hmac.new(
        self._trust_anchor._secret_key,
        message.encode('utf-8'),
        hashlib.sha256,
    ).hexdigest()
    
    # Compare with provided signature
    return hmac.compare_digest(identity.signature, expected)
```

### Tamper Behavior

- **Invalid signature**: Reject identity
- **Missing signature**: Reject identity
- **Signature mismatch**: Reject identity
- **Key not found**: Reject identity (fail-closed)

## E. Process Authentication

### Design

Implement real Windows process authentication using OS APIs. No fallback to `None`.

### Windows API

1. **GetNamedPipeClientProcessId**
   - API: `GetNamedPipeClientProcessId(HANDLE, PULONG)`
   - Library: `kernel32.dll`
   - Requirement: Windows Vista+
   - Purpose: Get actual client PID from OS

2. **Windows Security API**
   - API: `SetSecurityInfo`, `GetSecurityInfo`
   - Library: `advapi32.dll`
   - Purpose: Set DACL on named pipe

### Implementation

```python
class WindowsNamedPipe:
    """Windows named pipe with real process authentication."""
    
    def __init__(self, pipe_name: str, producer_pid: int):
        self.pipe_name = pipe_name
        self.producer_pid = producer_pid
        self.pipe_handle = None
        self._lock = threading.Lock()
    
    def create_server(self) -> None:
        """Create named pipe with DACL."""
        
        with self._lock:
            # Create security descriptor
            security_descriptor = self._create_security_descriptor()
            
            # Create named pipe with security
            self.pipe_handle = win32pipe.CreateNamedPipe(
                self.pipe_name,
                win32pipe.PIPE_ACCESS_DUPLEX,
                win32pipe.PIPE_TYPE_MESSAGE | win32pipe.PIPE_READMODE_MESSAGE,
                1,
                65536,
                65536,
                0,
                security_descriptor,  # DACL
            )
    
    def get_client_pid(self) -> int:
        """Get actual client PID from OS."""
        
        if self.pipe_handle is None:
            raise RuntimeError("Pipe not connected")
        
        # Call GetNamedPipeClientProcessId
        client_pid = ctypes.c_ulong()
        result = windll.kernel32.GetNamedPipeClientProcessId(
            self.pipe_handle,
            ctypes.byref(client_pid),
        )
        
        if result == 0:
            raise RuntimeError("Failed to get client PID")
        
        return client_pid.value
    
    def validate_client_pid(self, expected_pid: int) -> bool:
        """Validate client PID using OS API."""
        
        # Get actual PID from OS
        actual_pid = self.get_client_pid()
        
        # Compare with expected
        return actual_pid == expected_pid
```

### DACL Implementation

```python
def _create_security_descriptor(self) -> win32security.SECURITY_DESCRIPTOR:
    """Create security descriptor for named pipe."""
    
    # Get current process SID
    process_sid = win32security.GetTokenInformation(
        win32security.OpenProcessToken(
            win32api.GetCurrentProcess(),
            win32security.TOKEN_QUERY,
        ),
        win32security.TokenUser,
    )[0]
    
    # Create DACL
    dacl = win32security.ACL()
    
    # Grant access to current process only
    dacl.AddAccessAllowedAce(
        win32security.ACL_REVISION,
        win32con.FILE_ALL_ACCESS,
        process_sid,
    )
    
    # Create security descriptor
    security_descriptor = win32security.SECURITY_DESCRIPTOR()
    security_descriptor.SetSecurityDescriptorDacl(1, dacl, 0)
    
    return security_descriptor
```

### Fail-Closed Behavior

- **GetNamedPipeClientProcessId fails**: Reject connection
- **PID mismatch**: Reject connection
- **DACL creation fails**: Reject pipe creation
- **Client not authorized**: Reject connection

## F. IPC Trust Boundary

### Design

IPC trust boundary must enforce:
1. Process authentication (OS-level)
2. Producer scope validation
3. Transport identity vs application identity separation

### Trust Boundary Flow

```
Client connects
    ↓
GetNamedPipeClientProcessId (OS)
    ↓
Validate PID
    ↓
Validate producer scope
    ↓
Accept or Reject
```

### Implementation

```python
class IpcTrustBoundary:
    """IPC trust boundary enforcement."""
    
    def __init__(self, producer_pid: int, producer_scope: str):
        self.producer_pid = producer_pid
        self.producer_scope = producer_scope
    
    def validate_connection(
        self,
        pipe: WindowsNamedPipe,
    ) -> bool:
        """Validate IPC connection."""
        
        # 1. Get actual client PID from OS
        try:
            client_pid = pipe.get_client_pid()
        except RuntimeError:
            return False
        
        # 2. Validate PID
        if client_pid != self.producer_pid:
            return False
        
        # 3. Validate producer scope (application-level)
        # (This is validated via lease, not here)
        
        return True
```

### Separation of Concerns

- **Transport identity**: OS-level process identity (PID from GetNamedPipeClientProcessId)
- **Application identity**: TrustedExecutionIdentity (from RuntimeIdentityAuthority)
- **Producer scope**: Application-level authorization (from lease)

class LeaseIssuerService:

        self,

            expires_at=time.time() + ttl_seconds,
            consumed=False,
            signature="",
        )
        
        # Sign lease
        signature = self._sign_lease(lease)
        lease = dataclasses.replace(lease, signature=signature)
        
        return lease

## K. Threat Model

### Threats and Mitigations

| Threat | V3 Mitigation | V4 Mitigation |
|--------|--------------|--------------|
| Same-user malicious process | DACL TODO | DACL implemented |
| Wrong child process | PID validation (caller-provided) | GetNamedPipeClientProcessId (OS) |
| Spoofed PID | Application-level validation | OS-level validation |
| Cross-run replay | Runtime generation | Runtime generation + signature verification |
| Cross-session replay | Runtime generation | Runtime generation + signature verification |
| Restart stale lease | Runtime generation | Runtime generation + signature verification |
| Cross-generation use | Runtime generation | Runtime generation + signature verification |
| Malformed IPC | Message validation | Message validation + OS PID verification |
| Unauthorized pipe access | DACL TODO | DACL implemented |
| Fabricated identity | Validation (fail-open) | Verification (fail-closed) |
| Fabricated lease | Validation (fail-open) | Verification (fail-closed) |
| Unverified HMAC | Signature exists | Signature verified |
| Missing identity | Remove and continue | Raise error |

### Attack Scenarios

1. **Caller fabricates identity**
   - V3: Caller constructs CanonicalExecutionIdentity → accepted (generation matches)
   - V4: Caller constructs TrustedExecutionIdentity → rejected (signature verification fails)

2. **Caller fabricates lease**
   - V3: Caller constructs InternalMcpInvocation → accepted
   - V4: Caller constructs TrustedLease → rejected (signature verification fails)

3. **Wrong child process connects**
   - V3: Caller provides PID → accepted (caller-provided)
   - V4: GetNamedPipeClientProcessId returns wrong PID → rejected

4. **Stale identity after restart**
   - V3: Generation mismatch → rejected
   - V4: Generation mismatch + signature verification → rejected

5. **Missing identity in SelfAudit**
   - V3: Warning → remove → persist unbound evidence
   - V4: ValueError → reject → no persistence

V4 addresses this by implementing REAL security controls with fail-closed behavior and runtime verification.
